## Purpose

The general purpose of this app was to make a GUI front-end to [Wttr](https://wttr.in) to make it easier to get a condensed weather report for a multitude of locations across the United States.

## Install/Uninstall

Install: `curl -s https://github.com/melvinquick/wttrman/raw/branch/main/install.py | python3 -`  
Uninstall: `curl -s https://github.com/melvinquick/wttrman/raw/branch/main/uninstall.py | python3 -`
